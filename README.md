# 竹序 Zhuxu · 数字竹编工坊

[在线体验](https://zhuxu-bamboo-studio.bdjmcncfjbdjnc.chatgpt.site/)

支持编织纹样设计、配色调整、图片取色、单根竹条涂色、撤销、PNG/SVG 导出及文创产品效果预览。

## 本地运行

安装 Node.js 后，在仓库根目录运行：

```sh
node server.cjs
```

打开 http://localhost:4173 。网站不需要安装前端依赖或配置大模型 API 密钥。也可以将 `dist` 目录部署到静态托管平台。

## 目录

- `dist/`：可部署网站、交互代码与图片素材
- `server.cjs`：本地预览服务器
- `ASSETS.md`、`ASSET-v*.md`：素材出处和许可记录
- `QA-*`：原项目验证记录；测试脚本依赖原工作区工具，仓库未捆绑这些依赖

## 素材与边界

保留原站的 AI 生成样机与实拍图片标注；图片授权以素材记录为准。仓库公开不代表所有素材可任意商用。数字竹编结构和文创套样属于设计原型，未经实物生产验证。
